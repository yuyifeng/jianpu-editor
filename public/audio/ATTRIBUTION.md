# Audio sample attribution

The piano audio files in `piano/` are a reduced, single-velocity subset of
**Salamander Grand Piano V3**, recorded by **Alexander Holm**.

- Sample license: [Creative Commons Attribution 3.0](https://creativecommons.org/licenses/by/3.0/)
- Original archive: [Salamander Grand Piano V3](https://archive.org/details/SalamanderGrandPianoV3)
- MP3 package used for this subset: [`@audio-samples/piano-mp3-velocity9`](https://www.npmjs.com/package/@audio-samples/piano-mp3-velocity9)

The files are stored locally so the application does not fetch audio from a
third-party service at runtime. Sharp note filenames use `s` instead of `#`
(for example, `Ds4.mp3` represents `D#4`).
